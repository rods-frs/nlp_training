# NLP Training System – Pipeline de Dados Nativo 🚀

> **⚠️ STATUS: WORK IN PROGRESS (WIP)** > Este projeto está em desenvolvimento ativo. Algumas funcionalidades das versões mais recentes podem estar em fase de testes na `branch dev`.

Sistema de treinamento para modelos de **Named Entity Recognition (NER)** customizados, focado em alta performance e processamento nativo.

## 📈 Evolução das Versões

### 🔹 V1: Processamento Nativo
* **Foco:** Manipulação de dados brutos.
* **Funcionamento:** Uso exclusivo da biblioteca padrão do Python para extração e tratamento de datasets em CSV, garantindo leveza e zero dependências externas nesta etapa.

### 🔹 V2: Treinamento e Semântica
* **Foco:** Inteligência e estruturação.
* **Funcionamento:** Implementação do pipeline de treino utilizando `spaCy`. Os dados são convertidos em vetores semânticos para alimentar modelos NER de domínio específico.

### 🔹 V3: Engenharia e Escalabilidade (Branch Dev)
* **Foco:** Performance e manutenção.
* **Funcionamento:** Reestruturação lógica para suportar pipelines de dados em escala. Introdução de boas práticas de engenharia de dados para facilitar a expansão do sistema.

## 🛠️ Tecnologias Principais
* **Python** (Avançado/Standard Library)
* **spaCy** (NLP)
* **Pipeline ETL** (CSV/Datasets)

## 🚀 Como Testar (WIP)
1. Clone o repositório: `git clone https://github.com/rods-frs/nlp_training`
2. Mude para a branch de desenvolvimento para ver as últimas atualizações: `git checkout dev`
